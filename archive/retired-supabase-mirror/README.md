# Retired Supabase-to-Payload mirror path

These scripts were the former `lsites_core` seed/mirror design. They are kept
as read-only historical source, but they are deliberately outside the active
workspace, package scripts, deployment images, and CI. LiNKsites now uses
Supabase for versioned working content and evidence, then explicitly promotes
approved content to a Payload draft; there is no cadence-based mirror sync.

Do not restore these scripts to an active path without a separately approved
architecture change and migration plan.
