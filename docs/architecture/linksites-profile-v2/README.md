# LiNKsites Profile v2 planning authority

This directory is the canonical coordinated plan for rebuilding LiNKsites as an
independent Program composed from LiNKharness plus the LiNKsites Profile. It
incorporates the Master Website Template v2 consumer requirements from
LiNKlibraries without transferring provider-owned assets or contracts.

The existing `linktrend/LiNKsites` repository remains canonical. The migration
is a clean internal rebuild with selective reuse, additive data migration,
exact provider pins and rollback—not a new Profile repository.

Documents: `CANONICAL-PRD-ROADMAP.md`, `REMAINING-WORK-BASELINE.md`,
`WORK-PACKETS-AND-ISSUES.md`, `EXECUTION-MANIFEST.json`,
`MODEL-ROUTING-AUTHORITY.json`, and `PLANNING-VALIDATION.md`. The initial
manifest dispatches only LS-00. Later
tranches require rebaselined amendments binding exact LiNKharness and Master
Template checkpoints; A2/A3 remains separately gated after A1 proof.

This package authorizes no implementation, template admission, publication,
deployment or promotion. Those require separate execution tasks and the exact
cross-repository gates named here.
